# نظام الحضور والانصراف السحابي التفاعلي (HR Attendance System)
### متصل بقاعدة بيانات Google Sheets ومبني بـ React و Tailwind CSS

نظام متكامل واحترافي لإدارة الحضور والانصراف والموارد البشرية، يحول ملفات الإكسيل التقليدية إلى تطبيق ويب تفاعلي حديث وفائق السرعة يدعم اللغة العربية (RTL) ويعمل مع Google Sheets كقاعدة بيانات سحابية مركزية بدون أي تكاليف استضافة أو قواعد بيانات معقدة.

---

## 🌟 أبرز مميزات النظام

1. **لوحة تحكم تفاعلية (Interactive Dashboard):**
   - مؤشرات أداء فورية: نسبة الحضور اليومي، عدد الحاضرين، المتأخرين، الغائبين، والإجازات.
   - تسجيل سريع للحضور والانصراف بضغطة زر مع احتساب دقائق التأخير وساعات العمل تلقائياً.
   - مخطط بياني لتوزيع حضور الأقسام، وجدول بأحدث الحركات المسجلة.

2. **شيت الحضور اليومي (Daily Attendance):**
   - استعراض الحضور مع إمكانية التنقل بين الأيام السابقة والقادمة.
   - تصفية بالقسم، الحالة، والبحث بالاسم أو الرقم الوظيفي.
   - تسجيل فردي أو تسجيل جماعي (Batch Marking) لكافة موظفي قسم معين بنقرة واحدة.

3. **المصفوفة الشهرية الديناميكية (Monthly Matrix - 31 Days):**
   - بديل ديناميكي لشيتات الأشهر (سبتمبر، أكتوبر، نوفمبر، ديسمبر...) يدعم كافة سنوات وأشهر العام.
   - شبكة 31 يوماً توضح حالات الحضور برموز لونية مميزة (ح: حاضر، ت: متأخر، غ: غائب، ج: إجازة، ع: عطلة أسبوعية).
   - إحصائيات شهرية تلقائية لكل موظف: أيام الحضور، التأخير، الغياب، الإجازة، إجمالي الساعات، ونسبة الالتزام %.
   - نافذة فحص تفصيلية عند الضغط على أي خانة يوم.

4. **الملخص السنوي التراكمي (Annual Summary):**
   - إحصائيات سنوية متكاملة لكل موظف، مع تمييز أفضل موظف التزاماً، وأقل موظف تأخيراً.
   - تتبع استهلاك رصيد الإجازات السنوية والمرضية.

5. **دليل وإدارة الموظفين (Employee Directory):**
   - إضافة وتعديل بطاقات الموظفين مع ضبط مواعيد الدوام الخاصة والرواتب والأقسام.
   - إمكانية تفعيل أو تعطيل حساب الموظف.

6. **إدارة الإجازات والأذونات (Leaves Management):**
   - تقديم طلبات إجازة (سنوية، مرضية، طارئة...) واحتساب الأيام تلقائياً.
   - دورة اعتماد وموافقة/رفض للإدارة والموارد البشرية.

7. **مركز التقارير والطباعة (Reports & Print):**
   - تقارير رسمية جاهزة للطباعة والتصدير كـ PDF و Excel (.xlsx).
   - كشف حساب حضور موظف، تقرير التأخيرات، تقرير الغياب، وتقرير الإجازات.

8. **نظام الصلاحيات والرقابة (Roles & Audit Log):**
   - مستويات وصول: مدير نظام (Admin)، مسؤول موارد (HR)، مشرف قسم (Supervisor)، ومشاهد (Viewer).
   - سجل رقابة وتوثيق (Audit Log) غير قابل للتلاعب يرصد كل إضافة أو تعديل أو حذف.

9. **الربط السحابي والمزامنة مع Google Sheets (Cloud Sync):**
   - مزامنة ثنائية بدون وسيط خارجي عبر Google Apps Script Web App.
   - دعم التخزين المؤقت (Offline-First / Local Cache) لسرعة استجابة فائقة.

## 🚀 طريقة ربط Google Sheets كقاعدة بيانات (في 3 خطوات)

1. **إنشاء جدول بيانات جديد:**
   - توجه إلى [Google Sheets](https://sheets.new) وأنشئ جدولاً جديداً.

2. **إضافة كود Google Apps Script:**
   - من شريط القوائم اختر **Extensions (الإضافات)** > **Apps Script**.
   - احذف الكود الافتراضي والصق الكود الموجود في الإعدادات أو في ملف `src/services/googleSheetsAppScript.ts`.
   - اضغط على زر الحفظ (Ctrl+S / Cmd+S).

3. **نشر تطبيق الويب (Deploy Web App):**
   - اضغط على **Deploy** في الزاوية العلوية اليمنى > **New deployment**.
   - اختر النوع **Web app**.
   - اضبط **Execute as**: `Me` (حسابك).
   - اضبط **Who has access**: `Anyone` (أي شخص لديه الرابط).
   - اضغط **Deploy** وانسخ رابط تطبيق الويب الناتج (`Web app URL`).
   - افتح صفحة **الإعدادات** في نظام الحضور والصق الرابط واضغط **حفظ واختبار المزامنة**.

## 🛠️ التشغيل والتطوير محلياً (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

يعمل النظام محلياً على المنفذ: `http://localhost:3000`

---

## 📦 النشر على GitHub Pages أو Vercel / Netlify

لبناء النسخة الإنتاجية:
```bash
npm run build
```
سيتم إنشاء المخرجات في مجلد `dist/` الجاهز للنشر المباشر على أي استضافة ثابتة (Static Hosting) مثل GitHub Pages أو Vercel أو Cloud Run.
